# Grace Home Care Nursing Services

A professional, responsive website for **Grace Home Care Nursing Services** — a home care nursing agency based in Visakhapatnam, Andhra Pradesh, founded in 2022.

## About

Grace Home Care Nursing Services provides compassionate, professional in-home nursing and care services, including skilled nursing, elder care, pediatric care, doctor consultation, physiotherapy, and NRI care services.

## Features

- Fully responsive design (mobile, tablet, desktop)
- Animated hero with typewriter effect and rotating quotes
- 12 service cards with hover effects
- "How It Works" process section
- About section with dynamic years-of-experience counter
- Chairman's message
- Photo gallery with lightbox and load-more
- Customer reviews (Google)
- Contact form with client-side validation
- Floating WhatsApp and back-to-top buttons
- Scroll progress bar and reveal animations

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Poppins + Inter)

## Running Locally

Serve the folder with any static server, for example:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Structure

```
.
├── index.html      # Main page
├── styles.css      # All styles
├── script.js       # Interactions (nav, typing, gallery lightbox, form, etc.)
└── assets/         # Logo, photos, gallery images, favicon
```
